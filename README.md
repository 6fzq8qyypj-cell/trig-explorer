# Trig Explorer

Interactive HTML project to explore trigonometric functions on the unit circle. This project visualizes sine, cosine, tangent, cosecant, secant, and cotangent functions with live updates as you adjust angles.

## Features
- Fully interactive unit circle
- Live angle updates in degrees and radians
- Real-time visualization of sin, cos, tan, csc, sec, and cot
- Quadrant and RAA (Reference Angle) display
- Zoomable function graphs
- Predefined angle shortcuts and animation mode
- Customizable color-coded display

## How to Use
1. Clone or download the repository.
2. Open `index.html` in Google Chrome (or any modern browser).
3. Use the slider or click preset angles to see changes on the unit circle and graphs.
4. Toggle DEG/RAD mode or animation using the top bar buttons.
